# Local Development

## Supported environments

- Python 3.11+; the current verification environment is Python 3.13.9 with
  PyTorch 2.11.0+cpu and torchvision 0.26.0+cpu.
- Node 22.12+ and npm 11; the current frontend lockfile is generated by npm.

## Installation

From the repository root, install the backend in editable mode and the
frontend's locked dependencies:

```powershell
python -m pip install -e "app/backend[test]"
cd app/frontend
npm ci
cd ../..
```

## Environment variables

- `FEDRBTVIS_DATA_DIR`: default `data/`; contains the CIFAR-10 cache.
- `FEDRBTVIS_RUN_DIR`: default `runs/`; contains Run/Study artifacts.
- `FEDRBTVIS_LEGACY_DIR`: default `evidence/legacy/`; contains the imported
  historical evidence.
- `FEDRBTVIS_DEVICE`: `auto`, `cpu`, or `cuda`; default `auto`.

## Data

CIFAR-10 is expected at `data/cifar-10-batches-py`. The loader uses
`torchvision.datasets.CIFAR10(..., download=False)`, so the archive must be
prepared before selecting a `cifar10` preset. CIFAR-10 is provided by the
official University of Toronto archive and is the dataset source used by
torchvision. From the repository root, download and extract it with:

```powershell
New-Item -ItemType Directory -Force data | Out-Null
$archive = Join-Path $env:TEMP 'cifar-10-python.tar.gz'
Invoke-WebRequest 'https://www.cs.toronto.edu/~kriz/cifar-10-python.tar.gz' -OutFile $archive
tar -xzf $archive -C data
```

This produces `data/cifar-10-batches-py/`, matching the backend loader root.
`data/`, `runs/`, and `studies/` are ignored by Git.

## Run semantics

- Only one active Run is allowed per process.
- Stop requests are cooperative and take effect at client boundaries.
- On process restart, interrupted Runs are reindexed as `failed` with
  `PROCESS_INTERRUPTED`; a Run is never silently resumed.
- Events are persisted before broadcast; WebSocket replay uses
  `after_sequence` and does not invent missing events.

## Stable error codes

- `INVALID_CONFIG`: request validation failed.
- `RUN_NOT_FOUND`: unknown run id.
- `RUN_ALREADY_ACTIVE`: another Run is already active.
- `RUN_NOT_READY`: metrics are not available for an active Run.
- `ARTIFACT_CORRUPT`: persisted artifact or legacy evidence is corrupt.
- `LEGACY_NOT_IMPORTED`: the legacy endpoint has no imported evidence.
- `STUDY_NOT_FOUND`: unknown study id.

## Local-only workflow

All development and commits are local. Do not fetch, pull, push, open PRs, or
modify remotes unless the user explicitly authorizes a specific repository.
